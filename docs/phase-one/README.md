# 第一期候选包：范围与证据

本期围绕本人 AI 私聊、人格导入以及消息收发的可用性。基线为 `main` 的 `d9dc55d5cad6042bc6f3b3fe7da9b38cf15606c3`，与本地 `38cd86c` 的树 `3478ae317ae296f252ac44e7aade2aa0ca96fc93` 一致。

- **默认启动**：按[宿主说明](../host-setup.md)运行源码入口，无须手工设置模型 worker 的两个环境变量。已有的成对覆盖仍生效。使用模型仍须配置可用 Provider、绑定、人格和预算，并明确授权本人私聊。[运行时证据](runtime.md)将真实 worker 的注册/启动与合成模型的回复、落库和重启读回分别验证，未验证本次候选接入真实外部 Provider。
- **人格导入**：沿用[人格卡格式](../persona-card-format.md)，选文件或粘贴 JSON 后先填表单，由用户显式初始化或保存，不自动写入。
- **消息操作**：用户可复制可见文字、编辑本人的未撤回文本、在现有 24 小时宿主限制内确认撤回；确认回执更新本机消息镜像；具体操作及边界见[消息操作验证](msgops.md)。编辑标记只在本机；已经存到其他设备的旧正文和剪贴板不会被清除。不新增跨端变更投递协议。已有搜索、收藏、附件发送与图片预览保持原入口。
- **目前仍未提供**：系统新消息通知及锁屏正文隐私（[收件箱和未读审计](notify-gap.md)）；跨轮记忆及主动联系（[授权与调度审计](memory-proactive-gap.md)）；生产用加密备份、轮转和恢复（[导出与恢复审计](backup-restore.md)）。明文聊天导出和预览不等于备份。语音通话、Live2D 和 3D 世界不在此交付。

[独立复现与打包检查](release-verification-plan.md)列出可复跑命令及基线结果。候选包的 `VERIFICATION.md` 和 PR 保存对应树的实际测试与构建结果；基线通过不等于候选通过，Android debug APK 构建不等于真机验收。

候选包从同一代码树构建 Windows 客户端和 Android debug APK，并带有干净的配套宿主源码快照、相对路径启动脚本、示例人格和逐文件 SHA-256 校验。不覆盖旧包、旧源码或任何已有数据；切换前应停止旧宿主，并继续使用同一个已初始化的数据目录。
