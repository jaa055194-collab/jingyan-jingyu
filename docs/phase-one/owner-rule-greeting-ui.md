# 本人 AI 私聊 · 规则问候设置

客户端实现为 `8dd537be5fa639f9e58d768bd4cfaebc4546b1bb`，基线 `b915a33354a2e44dc2087dfe2f5e85eedc079c14` 与路由常量依赖 `684563b78a3891d0e31e18f8950f4b50828a3acc`。实际使用需要支持这两个路由的宿主（对应宿主切片 `f0023874ac1cf79aaa99cd6299f15613d096aadd`）。宿主未提供接口、拒绝访问或返回无效响应时，不显示为已关闭或已保存。

## 两个独立入口

- **设置 → 本人规则问候 · 账户级停止**：无需创建或选择 AI。只有读取或提交得到有效回执才显示开关状态。停止会撤回所有现有规则问候授权，保留日程；解除只移除总阻断，**不会**恢复任一个 AI 的授权。
- **设置 → AI 运行配置 → 本人规则问候**：选中自己的 AI 并解析到档案，先从宿主读取状态。默认关闭，与原有私聊许可和回复偏好无关。填写 24 小时制本地时刻、静默开始/结束和手动固定 UTC 偏移（`±HH:MM`，范围 `−14:00` 至 `+14:00`）。静默起止不能相同，可跨午夜；名义时刻落在静默窗内时延至结束再判断，不补发。偏移不随旅行或夏令时变动。
- 开启或修改已授权的日程，必须有有效的本人私聊、L3/L4、预算就绪、未全局停止和有效的固定偏移。客户端在显示确认前重新读取并比对授权、私聊及全局修订；确认展示具体 AI、范围和时间。宿主仍在写入时检查 CAS 和实时条件。撤回只发送关闭和**已保存**的日程，不接受未确认表单，也不需要最新的开启门槛。
- 「已授权」仅表示宿主报告的规则问候许可，**不保证发送**；预算不足可跳过已授权的时段。设置不读取聊天历史，不用模型，不开放其它收件人、任意内容、通知权限或活动记录。客户端不发送问候或安排后台计时器。
- 拒绝、冲突、未知结果分别提示；没有认证重放或自动写重试。切换 AI、账号、会话代际、连接或锁定会使旧视图确认失效；不会把迟到回执用于新会话。退页不代表取消已经发往宿主的写入。

## 本地验证

- 使用合成账号和回环/替身宿主边界，无真实账户设置或外部请求。基线中两个入口的 widget 用例因入口缺失而 RED；[API 用例](<../../apps/client_flutter/test/owner_rule_greeting_api_test.dart>)先复现首次授权传入有效偏移仍被拒绝、预算不足的已授权状态无法读取，以及非法时间戳被接受，再修复。
- 首次全量 `flutter test --no-pub --concurrency=4 --reporter expanded`：1,110 通过、3 跳过、2 失败。[开发者区测试](<../../apps/client_flutter/test/settings_developer_groups_test.dart>)的 `open-lifecycle-status opens BackupQuotaScreen` 和 `open-world-status opens WorldStatusScreen` 因新入口改变通用未绑定 Settings 的滚动位置，点击落在视口外。基线定向 3 项均通过；修复将新入口限制为实际客户端运行时，同一账号无 AI 时仍可使用。
- 修复后 `flutter analyze --no-pub` 无问题，定向 72 项通过（含上述两个回归、29 个规则问候 API/widget 用例与既有 AI 设置相关检查）。修复后的全量重跑在会话中断前最后记录为 **879 通过、3 跳过**，无最终汇总或退出码，**不计为全量通过**。
- [移动 Flutter 捕获与复现方法](<../../apps/client_flutter/evidence/owner-rule-greeting.md>)含两个同场景 Before/After 对，以及确认、撤回、全局停止截图。Widget 也检查了 375 / 768 / 1280 逻辑像素。未运行 Android 真机、原生安装、线上宿主或真实发送；不是发布验收。
