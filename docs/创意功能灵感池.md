## 2. 候选功能取舍清单

### 2.1 已采纳（v4.0 §13 创造性功能 CR-01～CR-12）

灵魂画布、时间胶囊、关系周报与年度报告、情绪天气、双人小剧场、共同目标、深夜电台、AI 群主持人、生成式礼物、记忆博物馆、语音信箱、便利贴。
取舍标准：围绕「AI 与人双向聊天并分享任何内容」；单人/双人即可产生价值；不依赖陌生人生态；隐私边界清晰可验收。

### 2.2 考虑过、本轮不采纳（含理由）

| 候选 | 理由 | 处置 |
|---|---|---|
| 多 AI 联动大剧本（AI 群体角色扮演世界） | 与 CR-05 双人小剧场、FR-43 L4 AI-AI 多轮重叠，复杂度高且易失控 | 后续评估 |
| AI 作曲/哼唱自制歌曲 | 音频生成厂商能力参差、成本高、验收困难 | 后续评估 |
| 数字信件（长期不活跃时的告别信） | 情感价值高但触发条件敏感，易变成打扰与伦理风险 | 后续评估，需默认关 + 多重确认 |
| 双人共读（同读一篇文章 + AI 逐段注解） | 有价值，但一期消息/引用体系已可低配实现（转发文章 + "问 AI"） | 列为二期候选 |
| AI 晨报（新闻/天气播报） | 通用信息对私人小圈子价值低；晨间规划（FR-42）已承载个人化部分 | 不采纳 |
| 表情包工坊独立模块 | 并入 CR-09 生成式礼物与 FR-55 贴纸生成开关 | 已并入 |
| AI 代拟回信/朋友圈文案一键代发 | 代发违反"草稿不代发"原则（FR-15） | 已并入为草稿模式 |
| 虚拟宠物养成小游戏 | 与生活引擎（FR-42）、悬浮宠物定位重叠 | 不采纳 |
| 手环/健康数据接入 | 硬件依赖与高敏隐私（T1/T2 级），成本收益比差 | 远期评估 |
| AR 拜访（摄像头叠加 3D 形象） | 依赖 3D 世界成熟（三期后），移动端性能风险高 | 远期评估 |
| 语音房 KTV/背景音 | 版权风险与音频管线复杂度 | 不采纳 |
| 匿名树洞/心情墙 | 与"私人朋友小圈子"定位冲突，匿名体系引入新权限面 | 不采纳 |

### 2.3 v3.1 → v4.0 结构性取舍

| 项 | 决定 | 理由 |
|---|---|---|
| 旧系统迁移/兼容（AstrBot 等旧栈） | 整体移除 | 用户明确"从 0 开发" |
| `PRIVATE_AI_PERSONA_1`专有人设与管理员记忆特例 | 移除，改为通用隐私边界 | 软件服务于多个朋友，不绑定单一 AI 人设 |
| 指定语音厂商（CosyVoice/火山） | 改为 provider 无关 + 音色工作台 | 避免厂商锁定；工作台保留同等的同意与保活约束 |
| 强制多租户实现细节 | 改为多用户隔离 + 串数据回归硬门槛 | 小圈子规模不需要租户级物理隔离，但回归要求不减 |
| iOS/macOS | 明确范围外 | 用户确认只做 Android + Windows |
| 分期交付 | 取消，改为依赖顺序的一次完整交付 | 用户确认 |
