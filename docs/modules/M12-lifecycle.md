# M12 · lifecycle：配额、清理、备份、导出导入、离开

> 依据：v4.2 FR-62～65、NFR-11、AC-14/15/29；口径 A-12、B-6、C-4。依赖：storage、messages。

## 要写的文件

```text
apps/host/lib/src/lifecycle/
  lifecycle_module.dart   name 'lifecycle'
  quota.dart              配额计量与上传闸门
  cleanup.dart            每日 03:30 单队列清理
  backup.dart             快照 → tar → age 加密 → 第二块盘 → 可选远端
  restore_drill.dart      恢复演练 + integrity_check
  export.dart             用户导出
  import.dart             导入：仅人格 / 人格 + 聊天记录
  departure.dart          用户离开与删除回执
```

## 规则

1. 配额（B-6）：每账号 20GB；80% 告警；100% 停 >50MB 上传，文字、小图、语音仍可发；磁盘 <10% 停全部新上传。分片 8MB，单账号并发上传 ≤3。
2. 清理：视频、语音 90 天过期删 blob，留占位"媒体已过期清理"；到期前 7 天提醒；共享媒体被一方清理后其他持有者保留占位。
3. 备份：age 加密，私钥离线保管；本地与远端各保留 30 天；远端只见密文；上传后校验 sha256。远端地址过 `UrlGuard`。
4. 恢复演练：下载 → 解密 → `PRAGMA integrity_check`，结果写审计。
5. 导出（口径 A-12）：该用户的**全部**数据，包含 `manifest.json`、`SHA256SUMS`、会话 JSONL、记忆快照、附件索引与附件。T2 与 API key 不出现明文（NFR-11）。
6. 导入（口径 A-12）：用户可选"仅人格"或"人格 + 聊天记录"；导入前校验 SHA256SUMS；与现有数据冲突时不覆盖，生成新 id 并在报告里列出。
7. 离开（口径 C-4）：由离开的用户自己决定其 AI 转交、保留或删除，以及既有私聊、共享内容与衍生物删除还是移交。生成删除回执（对象计数 + 备份轮转到期日）；只说"轮转后清除"。

## 验收

- [ ] AC-14 80%/100%/磁盘 <10% 三档行为分别正确；90 天清理删 blob 留占位。
- [ ] AC-15 备份文件是密文；30 天轮转；恢复演练 `integrity_check` 为 `ok` 并留记录。
- [ ] AC-15 删除用户后有回执；轮转后的快照不含其数据。
- [ ] AC-29 导出后再导入（人格 + 聊天记录）到空宿主，会话与记忆数量一致。
- [ ] A-12 选"仅人格"导入时不导入聊天记录。
- [ ] NFR-11 导出包里搜不到 T2 明文和 API key 明文。
