The adapter intentionally does not select files, grant consent, persist uploads, automatically retry uncertain stages, or enqueue/send messages. HTTP 401 authentication replay stays bounded by `HostConnection`; all other HTTP failures retain their existing classification. Completion validates canonical attachment ID, size and SHA-256 but does not attest to remote payload content unless a caller supplies the expected digest.
