拍摄条件（Before 和 After 相同）：

- Android 模拟器，API 36，1080×2400，420 dpi，浅色主题
- 状态栏演示模式（12:00）
- 应用连接本机回环地址上的合成宿主，用合成测试账号登录，数据都是临时合成数据
- `world-before` 和 `world-after` 都是底部导航「世界」页；`street-after` 是从这一页的按钮进入的街区页
- 拍 `street-after` 前，合成账号在合成宿主上保存了一份合成房间布局（modern 风格，两个空房间），所以街上有一栋「我的别墅」；没有布局时，街区页显示空街提示
